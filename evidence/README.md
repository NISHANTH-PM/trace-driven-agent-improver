# Evidence index

Every file here is generated by the code in this repository (or is a screenshot). Run files record `source` (`snapshot` = real Crustdata data, `fixtures` = fictional data) and, where present, the company names used.

## Current results (real Crustdata snapshots, corrected data and checks)

| File | What it is |
|---|---|
| `pack_run_20261012_003340.json`, `..._003422.json`, `..._003506.json` | Three full improvement cycles: baseline versus candidate on 6 development and 4 held-out companies, with failure counts, proposals, promotion decision and cost |
| `pack_ablation_20261012_003253.json` | Six configurations (baseline, retry only, strict prompt only, verify only, strict + verify, candidate) on both splits |
| `real_data_results.md` | The two tables above in readable form, with the 10 companies |
| `office_outputs_20261012_085329.json` / `.md` | Candidate run producing .docx, .pptx and .xlsx for all 10 companies, with the deterministic artifact check, evaluator verdict, tokens and cost |
| `demo_manifest.md` | Labeled demo scenarios (baseline wrong fact, tool error, retry recovery, candidate success, verification regeneration) with start times, true values versus written text, and what to search for in neatlogs |
| `diagnosis_20261011_224432.md`, `diagnosis_20261011_224831.md` | Diagnosis of the candidate's failures on real data before and after the fact-check formatting fix (false mismatches such as `series_d` versus "Series D") |
| `git_history.txt` | Commit dates, to show the code was written during the hackathon |
| `screenshots/` | neatlogs traces, Entire pages, cfo.ai pages, generated documents (`README.md` there lists them; `LINKS.md` holds trace links) |
| `entire_graph/` | Output of `entire graph` commands, if present |

## Kept for transparency, not comparable to the results above

| Folder | Why it is kept |
|---|---|
| `superseded/` | Runs made before data or checks were corrected: mismatched companies (meesho.com, notion.so), checker formatting false mismatches, office runs without token counters, and earlier office outputs. `superseded/README.md` explains each file |
| `synthetic_fixtures/` | Early runs on fictional fixture companies, before real Crustdata data was used |
